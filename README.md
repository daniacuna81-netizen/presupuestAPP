# PresupuestAPP 🚀

**PresupuestAPP** es una aplicación web SaaS B2B moderna, ligera y de archivo único diseñada para contratistas, instaladores, electricistas, plomeros y profesionales de obras y reformas. Permite generar presupuestos comerciales profesionales, cómputos métricos de materiales y propuestas técnicas duales (Económica vs. Premium) en segundos.

---

## ✨ Características Principales

* 📊 **Cómputo Métrico por Rubros Técnicos:**
  * **Electricidad:** Canalizaciones, cables normalizados, módulos y tableros.
  * **Paredes y Tabiques (Drywall / Tradicional):** Estructuras, perfiles, fijaciones, placas RH, mampostería, cemento y arena.
  * **Plomería y Sanitarios:** Termofusión, desagües PVC, artefactos y griferías.
  * **Pintura y Acabados:** Látex lavable, impermeabilizantes, rodillos y lijas.
  * **Partidas Libres:** Carga rápida de insumos o servicios a medida.

* ⚖️ **Presupuesto Dual (Económico, Estándar y Premium):**
  * Comparativa transparente entre opciones de costo y primeras marcas con garantías extendidas.
  * Selección de propuesta activa para emisión limpia en PDF o envío instantáneo por WhatsApp.

* 📱 **Simulador Móvil en Vivo:**
  * Alterna entre modo escritorio y vista smartphone táctil con marco de dispositivo integrado.

* 🌍 **Multimoneda y Multilenguaje:**
  * Precios de referencia calibrados para **Argentina (AR$)**, **España (€)** y **Estados Unidos (US$)**.
  * Conmutador dinámico de idioma **Español (ES)** e **Inglés (EN)**.

* 🏢 **Personalización B2B y Modelo Freemium:**
  * Carga de logotipo corporativo con compresión automática en base64.
  * Gestión de proyectos múltiples guardados en `localStorage`.
  * Exportación a PDF corporativo limpio y configurable.

---

## 🛠️ Tecnologías

* **HTML5 + CSS3 + Vanilla JavaScript (ES6+)**
* **Tailwind CSS** (vía CDN para estilos responsivos e interactivos)
* **Lucide Icons**
* **Canvas API** (compresión y procesamiento de imágenes cliente)
* **LocalStorage API** (persistencia de matrices de precios, proyectos y configuraciones)

---

## 🚀 Cómo Usar

1. Clona este repositorio o descarga el archivo `index.html`.
2. Haz doble clic en `index.html` para abrirlo en cualquier navegador web moderno (Chrome, Edge, Safari, Firefox).
3. No requiere servidor local, Node.js ni bases de datos externas para su funcionamiento básico.
